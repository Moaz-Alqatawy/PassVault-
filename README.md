# PassVault

تطبيق سطح مكتب أصلي لنظام Windows لإدارة الحسابات، بواجهة عربية من اليمين إلى اليسار. تُحفظ البيانات محليًا داخل خزنة مشفّرة؛ لا يحتاج التطبيق إلى خادم أو حساب سحابي أو اتصال بالإنترنت.

## التقنية

يستخدم التطبيق **WPF على .NET 10**: إطار واجهات ناضج ومدمج في Windows، ويدعم .NET 10 نشرًا ذاتي التشغيل طويل الدعم. لا يعتمد المشروع على حزم خارجية. تُشتق مفاتيح التشفير باستخدام PBKDF2-HMAC-SHA256 مع 600,000 تكرار وملح عشوائي بطول 16 بايت، وتُشفّر الخزنة باستخدام AES-256-GCM و nonce جديد عند كل حفظ.

## المتطلبات

- Windows 10 أو أحدث (x64)
- .NET 10 SDK للبناء من المصدر
- طابعة PDF، مثل **Microsoft Print to PDF**، لحفظ ملفات PDF

## البناء والتشغيل

من PowerShell في مجلد المشروع:

```powershell
dotnet restore .\PassVault\PassVault.csproj
dotnet build .\PassVault\PassVault.csproj -c Release
dotnet run --project .\PassVault\PassVault.csproj
```

ينشئ التشغيل الأول خزنة محلية بكلمة المرور الابتدائية المطلوبة `0979`، ويعرض تنبيهًا بأنها ضعيفة. غيّرها من **الإعدادات ← تغيير كلمة المرور الرئيسية** قبل حفظ بيانات حقيقية. يجب أن تتكون كلمة المرور الجديدة من 8 أحرف على الأقل.

لبناء ملف Windows تنفيذي مستقل لا يحتاج مستخدمه إلى تثبيت .NET:

```powershell
dotnet publish .\PassVault\PassVault.csproj -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true `
  -o .\publish\win-x64
```

شغّل `.\publish\win-x64\PassVault.exe`. للبناء على Windows ARM64 استبدل `win-x64` بـ`win-arm64`.

لتشغيل اختبارات التشفير والتخزين:

```powershell
dotnet run --project .\PassVault.Tests\PassVault.Tests.csproj -c Release
```

## موقع البيانات والنسخ الاحتياطي

تُنشأ الخزنة المشفّرة تلقائيًا في:

```text
%LOCALAPPDATA%\PassVault\vault.pv
```

يُحفظ إعداد مدة القفل التلقائي، من دون أي بيانات حسابات أو كلمات مرور، في `%LOCALAPPDATA%\PassVault\settings.json`. تعرض صفحة الإعدادات مسار الخزنة وتتيح فتح مجلدها. يستخدم حفظ الخزنة وتغيير كلمة المرور ملفًا مؤقتًا ثم الاستبدال لتفادي ترك ملف جزئي عند انقطاع الكتابة.

من **الإعدادات ← إنشاء نسخة احتياطية مشفّرة** احفظ نسخة `.pv` في مكان آمن. تظل النسخة مشفّرة بكلمة المرور الرئيسية المستخدمة وقت إنشائها. للاستعادة، اختر النسخة وأكّد الاستبدال وأدخل كلمة مرورها؛ يتحقق التطبيق منها قبل استبدال الخزنة. أنشئ نسخة من البيانات الحالية قبل الاستعادة إن كنت قد تحتاج إليها.

يفتح تصدير PDF نافذة الطباعة في Windows؛ اختر **Microsoft Print to PDF** ثم حدد مكان الملف. تضمين كلمات المرور معطّل افتراضيًا، ويعرض التطبيق تحذيرًا قبل إنشاء PDF يتضمنها. لا يحمي PDF بكلمة مرور PassVault؛ احفظه واطبعه وشاركه بحذر.

## أساسيات الأمان

- لا تُكتب كلمة المرور الرئيسية نفسها في ملف الخزنة أو الإعدادات. تُستخدم قيمة salt عشوائية ومفتاح مشتق بـPBKDF2 لكل مفتاح خزنة.
- تُشفّر بيانات الحسابات، بما فيها كلمات مرورها وملاحظاتها، محليًا باستخدام AES-GCM. لا يسجل التطبيق بيانات الحسابات.
- كلمات مرور الحسابات مخفية افتراضيًا في الجدول. تُمسح كلمة المرور المنسوخة من الحافظة بعد 30 ثانية إذا بقيت القيمة نفسها فيها.
- تُقفل الخزنة تلقائيًا بعد خمس دقائق من عدم النشاط افتراضيًا. يمكن ضبط المدة من الإعدادات بين دقيقة واحدة و120 دقيقة.
- نسيان كلمة المرور الرئيسية يمنع استعادة الخزنة ونسخها الاحتياطية؛ لا توجد آلية لإعادة تعيين كلمة المرور أو مفتاح استرداد.
- قد يكشف جهاز Windows أو حساب مستخدم مخترق البيانات أثناء فتح الخزنة. حافظ على تحديث Windows، واستخدم تشفير الجهاز، واحمِ ملفات النسخ الاحتياطية.

## GitHub ونظافة المستودع

يتجاهل `.gitignore` ملفات البناء والنشر والخزن والنسخ الاحتياطية وملفات PDF والمفاتيح الشائعة. تُحفظ بيانات الخزنة في مجلد AppData للمستخدم، وليس داخل مجلد المشروع. راجع `git status` قبل رفع المشروع للتأكد من عدم إضافة ملفات شخصية.
